MetraCheck NAWI Assessment Prototype

Run the project with a local static web server and open index.html. See README.md for the modular project structure, workspaces, and prototype limitations.

This is a front-end demonstration. Authentication and authority integrations are not implemented. Demo measurement thresholds are not verified OIML R-76 or legal-metrology requirements. Do not use the prototype for official decisions or real personal/confidential records.
